# BODYCAM NEXT — Industrial Afterlight (Stage 01)

A completely new browser-based, asset-first industrial room prototype built with Next.js, TypeScript and Babylon.js.

**Development status:** Stage 1 is not yet accepted. No weapons, characters, or multiplayer.

## Goals
- Single 12 x 12 x 6 metre industrial room.
- Poly Haven CC0 GLB assets and PBR materials.
- Mobile camera controls and `/dev/assets` inspection lab.
- Declarative `data/level.layout.json` and placement validators.

## Local development
```sh
npm ci
npm run dev
npm run build
```

Source and asset files are in preparation. Visual quality and mobile performance are not yet accepted.
